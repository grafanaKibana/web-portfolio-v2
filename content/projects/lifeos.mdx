LifeOS is a personal operating vault for connected notes, dashboards, structured records, and repeatable workflows across everyday domains.

## Outcome

Markdown remains the durable source of truth while dashboards make active information easier to scan on desktop and mobile.

## Role

Owner, designer, and maintainer of the vault structure, local automation, responsive dashboard components, and approval-first capture flows.

## Architecture

Obsidian stores the underlying notes. Datacore JSX renders local dashboards, JavaScript actions handle controlled mutations, and CSS adapts shared components to the active theme and available width.

## Workflow design

Capture and enrichment flows prepare drafts for review instead of silently filing data. Bases, templates, note toolbars, and local scripts reuse the same Markdown records rather than introducing a separate database.

## Constraints

The system remains local-first, theme-aware, usable on mobile, and readable as ordinary Markdown when richer views are unavailable.
