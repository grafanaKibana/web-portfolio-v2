Colsdown adds responsive multi-column and stacked layouts to Obsidian without replacing the underlying Markdown.

## Outcome

Fenced `colsdown` and `stack` blocks render as adaptive layouts in Reading View, then collapse below a configurable container width without horizontal overflow.

## Role

Creator and maintainer of the parser, renderer, editor commands, responsive behavior, release workflow, and documentation.

## Content model

Column separators support percentages, fractional tracks, automatic widths, and nested code fences. Notes remain readable in source form, and every insertion is an ordinary undoable editor change.

## Runtime

The plugin runs on desktop and mobile, uses Obsidian's renderer, and makes no network requests or telemetry calls.
