Tabsdown keeps one fenced Markdown syntax usable in an Obsidian vault and on a Quartz-published website. The product spans two repositories so each integration can follow its host platform without duplicating the content format.

## Outcome

The same source renders as interactive tabs in Obsidian and Quartz while remaining readable Markdown when neither integration is active. Tab bodies continue through each platform's normal Markdown pipeline, including links, embeds, callouts, math, diagrams, and syntax highlighting.

## Role

Creator and maintainer of the shared syntax, both platform integrations, styling options, tests, releases, and documentation.

## Obsidian integration

The Obsidian plugin renders tabs in Reading View and Live Preview using Obsidian's Markdown renderer. The first tab starts active, keyboard behavior remains accessible, nested tab sets keep independent state, and responsive density adapts to mobile and narrow containers.

## Quartz integration

The Quartz transformer parses the same tab syntax before Obsidian Flavored Markdown so downstream transformers can process each tab body normally. Optional appearance settings are validated during the build instead of silently producing inconsistent output.
