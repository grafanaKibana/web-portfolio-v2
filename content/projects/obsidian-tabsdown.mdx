## About

Tabsdown turns Markdown into accessible, theme-native tabs in Obsidian and Quartz. Write layouts with comment markers or fenced blocks, use them in Obsidian Reading View and Live Preview, and publish the same source through Quartz.

In Obsidian Live Preview, the active tab's body can be edited in place with a plain Markdown editor. Escape returns to the rendered content, switching tabs retains edits, and changes use Obsidian's Undo and Redo history. Tabs can be added, renamed, or removed without rebuilding the layout by hand.

In Obsidian, tab bodies use the native Markdown renderer, keeping links, embeds, callouts, math, diagrams, highlighted code, and compatible plugin blocks available inside tabs. Quartz processes supported content through its own Markdown and Obsidian Flavored Markdown transformers.

## Highlights

- Works in Obsidian Reading View and Live Preview on desktop and mobile.
- Supports comment markers and fenced blocks, including layouts nested across both formats.
- Edits the active tab in place in Live Preview while preserving the note's Markdown source and undo history.
- Supports nested tab sets, Lucide icons, limited label formatting, four tab-list positions, wrapping, density, and appearance options.
- Uses Style Settings for global styling and a context menu for individual layouts.
- Keeps the original source readable when the plugin is inactive or the note is opened elsewhere.
- Quartz emits every labelled panel as readable HTML before JavaScript adds tab behavior.
- Pointer, touch, arrow-key, `Home`, and `End` navigation are supported.

## How it works

Comment markers surround ordinary Markdown and label each tab. A layout needs at least two non-empty, unique labels.

```markdown
%% tabs %%
%% tab: Notes %%
Plain Markdown content

%% tab: Example %%
`code` and other Markdown
%% endtabs %%
```

Fenced `tabsdown` blocks remain supported with the same layout features. Optional configuration appears before the first `tab:` label.

```markdown
~~~tabsdown
tab: Notes
Plain Markdown content

tab: Example
`code` and other Markdown
~~~
```

In Obsidian, the plugin delegates rendered bodies to Obsidian's Markdown renderer and writes in-place edits back into the original layout. In Quartz, the transformer recognizes both formats before Obsidian Flavored Markdown, inserts each body into the syntax tree, and lets later transformers process it normally. Quartz reports malformed layouts with their original source; incomplete layouts in Obsidian can reveal the note's source for editing.
