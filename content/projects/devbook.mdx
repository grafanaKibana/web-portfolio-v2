DevBook keeps one curated source of engineering notes useful in three places: an Obsidian learning system, a public static website, and hands-on retrieval experiments.

## Outcome

One curated source supports a public website covering 11 topic areas and retrieval experiments with ingestion, chunking, embeddings, vector search, reranking, and evaluation.

## Role

Creator and maintainer, with sole ownership of the note system, published site, and retrieval backend.

## One source, different uses

The notes remain readable source files. Quartz publishes them as a website, while the retrieval work explores ingestion, chunking, embeddings, vector search, reranking, and evaluation over the same material.

## Architecture

`Ingestion → chunking → embeddings → vector search → reranking`

## Stack

- Obsidian
- Quartz
- .NET
- RAG
- Embeddings
- Vector search
- Retrieval evaluation
